# Espaço e forma

Tudo é múltiplo de **4 px**. Padding, gap, raio e espessura de traço usam sempre estas variáveis, que
vêm da coleção **Dimensions** do Figma.

## Raio e traço

O sistema é **quadrado**: raio 0 por padrão. `radius-full` existe só para círculos (avatar, switch).
Linhas são finas: 1 px (`hairline`) para bordas e divisores, 2 px (`strong`) para foco.

## Navegação

`--nds-layout-nav-height` fixa a altura da barra de navegação em **64 px**.
