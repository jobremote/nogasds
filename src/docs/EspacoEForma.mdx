# Espaço e forma

Tudo é múltiplo de **4 px**. Componentes e telas usam **só os tokens semânticos** da coleção **Layout**
(Foundations no Figma). Os valores vêm da coleção **Dimensions** (Primitives), e só os tokens de Layout apontam
para ela: nunca use um primitivo direto.

## Espaço

Dois papéis, com a mesma escala: **gap** é o espaço entre itens irmãos (gap e margens entre elementos) e
**inset** é o espaço interno de um contêiner (padding).

## Raio e traço

O sistema é **quadrado**: `--nds-radius-default` é 0. `--nds-radius-round` existe só para formas circulares
(avatar, radio, ponto de status). Linhas são finas: 1 px (`--nds-stroke-default`) para bordas e divisores e 2 px
para o anel de foco (`--nds-stroke-focus`) e para erro e status (`--nds-stroke-emphasis`).

## Navegação

`--nds-size-nav-height` fixa a altura da barra de navegação em **64 px**.
