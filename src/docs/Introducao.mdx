## Para que serve

O NogasDS não pertence a nenhum produto. É a base reutilizada em tudo o que é concebido aqui: cada
produto experimental já nasce com um visual coerente e com opinião, em vez de começar de uma tela em
branco, e o sistema evolui com o que cada experimento revela.

O objetivo é duplo. Primeiro, **dar caráter** aos produtos: um visual escuro, editorial e quadrado,
com contraste feito de peso tipográfico e linhas finas. Segundo, servir de **chão de estudo** para
construir design systems de produto: tokens, temas, componentes acessíveis e documentação, tudo no
mesmo lugar e ligado ao Figma.

## Usar em um produto

O pacote ainda não está no npm. Instale direto do GitHub, por tag:

```bash
npm install github:jobremote/nogasds#v0.2.0
```

```tsx
import 'nogasds/styles.css';
import { Button, TextField } from 'nogasds';
```

A fonte Inter não vem embutida: carregue os pesos 300, 400, 500 e 700. O tema claro se ativa com
`data-theme="light"` em qualquer ancestral. Detalhes no
[README](https://github.com/jobremote/nogasds#readme).
